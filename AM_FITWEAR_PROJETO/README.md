# AM FITWEAR — loja virtual demonstrativa

Projeto acadêmico fictício desenvolvido com HTML, CSS e JavaScript puro.

## Como executar no VS Code
1. Extraia a pasta `AM_FITWEAR_PROJETO.zip` para um local do computador.
2. Abra o Visual Studio Code.
3. Clique em **Arquivo > Abrir Pasta** e selecione `AM_FITWEAR_PROJETO`.
4. Abra `index.html`.
5. Para visualizar, clique com o botão direito no `index.html` e escolha **Open with Live Server**, caso tenha a extensão Live Server instalada. Se não tiver, abra o arquivo `index.html` diretamente no navegador.

## Estrutura
- `index.html`: estrutura e conteúdo da loja.
- `css/style.css`: identidade visual, layout e responsividade.
- `js/script.js`: pesquisa, filtros, carrinho e checkout simulado.
- `img/produtos/`: imagens usadas no projeto.

## Funcionalidades
- Navegação por seções e coleção de produtos.
- Pesquisa e filtros por categoria.
- Adição de produtos ao carrinho.
- Alteração de quantidades e cálculo do subtotal.
- Tela de checkout ilustrativa.

## Importante
Este projeto é apenas uma demonstração. Os preços e o frete são fictícios. O checkout não envia pedidos, não armazena dados e não processa pagamentos reais. Antes de uma eventual publicação comercial, revise preços, disponibilidade, direitos de uso das imagens, informações da loja e requisitos de privacidade.
